# Individual recording guide (8-12 minutes)
0:00-0:45 Introduce your name, student ID, exact topic and objective.
0:45-2:00 Explain Stop-and-Wait, alternating sequence bits and ACK numbering.
2:00-3:00 Explain React, Python event logic and the configuration fields.
3:00-4:00 Run Normal Delivery. Point out first ACK at 300 ms.
4:00-6:00 Run Delayed ACK paused. Step through 100, 600, 700 and 1100 ms. Explain why the receiver delivers only once. Show the trailing ACK at 1700 ms.
6:00-7:00 Run Adjusted Timeout. Explain unchanged ACK arrival but no retry.
7:00-8:30 Show comparison measurements and download evidence. Try a custom input and explain the predicted outcome before running it.
8:30-9:30 Solve the exam question and explain assumptions.
9:30-10:00 Conclude and show reproducible project files.

Practise before recording. Narrate in your own words. Upload your own video and verify viewer access. Do not read an unfamiliar script as a substitute for understanding the code.
